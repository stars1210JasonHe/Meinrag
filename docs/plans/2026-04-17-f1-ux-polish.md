## Change: Active source highlight

### Problem
When a user clicks a source in the right-side Sources panel, the PDF viewer opens at that source's location, but **the source item itself shows no visual indication of being active**. Users can't tell at a glance which source is currently displayed in the PDF viewer, and if they scroll the sources list they lose track.

### Design
- Pass `isActive` boolean prop to `SourceItem`.
- When active: add a left border accent + subtle background tint.
- Keyboard nav already works (ArrowUp/ArrowDown changes `selectedSource`), so the highlight will follow keyboard navigation automatically.

### Implementation

**File 1: `frontend/src/components/SourceItem.jsx`**

Current button (line 19-22):
```jsx
<button
  onClick={() => onClick(index)}
  className="flex items-start gap-2 w-full px-3 py-2.5 text-left rounded-lg transition-colors hover:bg-white/5"
>
```

Change to accept `isActive` and apply conditional styling:
```jsx
export default function SourceItem({ source, index, isActive, onClick }) {
  // ...
  return (
    <button
      onClick={() => onClick(index)}
      className={`flex items-start gap-2 w-full px-3 py-2.5 text-left rounded-lg transition-colors ${
        isActive
          ? 'bg-white/10 border-l-2 border-[hsl(168_84%_40%)]'
          : 'hover:bg-white/5 border-l-2 border-transparent'
      }`}
    >
```

Using the same teal color (`hsl(168 84% 40%)`) that's already used elsewhere for accent. The `border-l-2 border-transparent` on the inactive state prevents layout shift when the active state is applied.

**File 2: `frontend/src/pages/ChatPage.jsx`**

Current call (line 562):
```jsx
<SourceItem key={i} source={s} index={i} onClick={setSelectedSource} />
```

Change to pass `isActive`:
```jsx
<SourceItem
  key={i}
  source={s}
  index={i}
  isActive={i === selectedSource}
  onClick={setSelectedSource}
/>
```
